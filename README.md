# 医院管理系统 — 软件质量保证与测试项目

> 被测系统：医院管理系统（患者 / 分诊 / 医生 / 科室四大业务模块）

## 项目简介

模拟医院后台管理系统的 18 个 HTTP 接口，围绕**功能正确性、代码分支逻辑、异常容错、接口契约、并发性能**五个维度开展完整测试，共设计并执行 **125 条测试用例**，记录 **3 条缺陷**并完成修复闭环。

| 测试类型 | 使用方法 | 用例数 | 文档 |

## 关键数据

- **用例总数**：125 条（黑盒 97 / 白盒 24 / 专项 4），修复后通过率 100%
- **缺陷**：3 条（S2 严重 1、S3 一般 1、S4 轻微 1），严重缺陷已修复回归
- **性能**：JMeter 5 并发 / 5 秒，样本 3967 个，错误率 0.00%，平均响应 3 ms，吞吐量 793.1 req/s
- **代码覆盖**：服务层 8 种白盒方法覆盖，环形复杂度 V(G)=4 的接口完成全部独立路径覆盖
